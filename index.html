EchoHeaders

A minimal Go HTTP service packaged as a small network console with usefull modules

How to deploy

Three supported ways: local Docker, Kubernetes manifests, or the Helm chart from this site's repository at /charts.

Docker local / single host

Build and run the container. Port 8080 is exposed; the image ships with curl, ping, traceroute, and dig.

docker build -t echoheaders .
docker run --rm -p 8080:8080 echoheaders

# or with Docker Compose
cd deploy/docker
docker compose up -d

Rate limits per minute per IP: RATE_LIMIT_PING, RATE_LIMIT_TRACEROUTE, RATE_LIMIT_DNS (default 10 each).

Kubernetes kubectl apply

Manifests in deploy/kubernetes/ (Deployment, Service, Traefik Ingress). Set the image registry, ingress host, and namespace first. The NET_RAW capability is required for ping/traceroute.

# after building & pushing the image:
docker build -t <registry>/echoheaders:<tag> .
docker push <registry>/echoheaders:<tag>

kubectl apply -f deploy/kubernetes/
kubectl -n <namespace> rollout status deployment/echoheaders

Helm recommended

The chart is published automatically to the Helm repository on every push to main.

helm repo add echoheaders https://echoheaders.is-a.dev/charts
helm repo update

helm upgrade --install echo echoheaders/echoheaders \
  --namespace echoheaders --create-namespace

# useful overrides:
helm upgrade --install echo echoheaders/echoheaders \
  --namespace echoheaders --create-namespace \
  --set ingress.hosts[0].host=echo.example.com \
  --set replicaCount=2

Verify: helm test echo --namespace echoheaders · Repo index: /charts/index.yaml
